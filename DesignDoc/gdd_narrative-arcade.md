# Диздок 3: Гибрид «Инфест» (аркада-новелла с roguelite-элементами)

## Жанр
Графическая новелла + аркадные мини-игры + roguelite. Нарративные секции чередуются с геймплейными. Развилки приводят к разным исходам. Смерть обучает. Несколько прохождений одного паразита раскрывают разные аспекты его биологии.

## Основная концепция
Игрок — паразит, рассказывающий свою историю «от первого лица» (с иронией и характером). Между экшн-секциями — диалоговые экраны с выборами. Неправильный выбор → смерть → новая информация → повторное прохождение с новым знанием. Цель — пройти полный цикл без смертей, используя накопленные знания.

## Механики/системы

### Структура прохождения

Каждая «кампания» (один паразит) состоит из **глав**. Каждая глава = одна стадия жизненного цикла.

```
Глава состоит из:
1. [Нарратив] — текст от лица паразита, описание ситуации, научная справка
2. [Выбор]    — развилка (1–3 варианта), влияет на следующую секцию
3. [Экшн]     — мини-игра, определяемая стадией и выбором
4. [Исход]    — успех → следующая глава / провал → экран смерти + факт
```

### Нарративная система

#### Рассказчик
Паразит «говорит» от первого лица. Тон — ироничный, но информативный:

```
"Итак, я — яйцо описторха. Звучит не очень гламурно, согласен. 
Мне нужно попасть в воду и найти моллюска рода Codiella. 
Именно Codiella, не какого-нибудь другого — я разборчив в первых хозяевах.
Кстати, при температуре выше 60°C я погибаю. Запомни это. Пригодится."
```

Рассказчик **прямо даёт подсказки**, замаскированные под хвастовство или жалобы. Внимательный игрок запоминает факты и использует их при выборах.

#### Выборы
Каждый выбор — это **биологическая развилка**. Один вариант правильный, остальные — ловушки:

```
Ты — церкария, вышедшая из моллюска. Перед тобой три рыбы:
  A) Карп — крупный, медленный, легко внедриться
  B) Язь — средний, из семейства карповых  
  C) Щука — хищник, но в ней много питательных веществ

[Правильный: B — описторх заражает именно карповых рыб, 
 но карп в данном регионе не типичный хозяин]
[A — частично правильный, зависит от контекста, но менее оптимальный]
[C — смерть: щука не является промежуточным хозяином описторха]
```

#### Последствия выборов
- **Правильный выбор:** продолжение + бонус к здоровью/энергии в мини-игре
- **Частично правильный:** продолжение, но с штрафом (меньше HP в следующей мини-игре, сложнее условия)
- **Неправильный:** экран смерти

### Roguelite-система

#### Знание сохраняется между попытками

При каждой смерти игрок получает **«Биологический факт»** — он добавляется в **Энциклопедию** (доступна из меню). В следующей попытке:
- Неправильные варианты, на которых игрок уже умирал, помечены черепом (опционально, можно отключить для хардкора)
- Открываются **альтернативные пути** — дополнительные варианты выбора, доступные только после определённых смертей

```
Пример:
Попытка 1: Игрок выбрал щуку → смерть → факт: "Описторх заражает только карповых"
Попытка 2: Вариант "Щука" помечен черепом. Игрок выбирает язя → успех
Попытка 2 (альт): Появился новый вариант "Плотва" (тоже карповая) → 
  открывается, только если игрок умер на щуке и узнал про карповых
```

#### Счётчик попыток
- «Идеальное прохождение» (0 смертей) — максимальная оценка
- Каждая смерть снижает итоговый балл, но открывает контент
- Мотивация: пройти заново чисто, используя все накопленные знания

### Мини-игры (экшн-секции)

Каждая стадия имеет **свой тип мини-игры**. Мини-игры короткие (30–90 секунд).

#### Тип 1: «Доплыви» (навигация)
- Вид сверху, 2D
- Паразит плывёт/ползёт к цели
- Препятствия: течения, хищники, ультрафиолет (поверхность воды)
- Управление: мышь или WASD
- Используется для: свободноживущие стадии в воде, миграция по кровеносной системе

#### Тип 2: «Спрячься» (стелс)
- Арена, вид сверху
- Иммунные клетки патрулируют зону
- Игрок должен добраться до укрытия (целевого органа/ткани), не попавшись
- Конусы зрения у макрофагов, случайные патрули нейтрофилов
- Используется для: миграция по организму хозяина

#### Тип 3: «Пробейся» (ритм/тайминг)
- Боковой вид
- Серия барьеров (ткани, мембраны, слизистая)
- Игрок нажимает кнопку в нужный момент (когда индикатор в зелёной зоне)
- Чем точнее — тем меньше урона / энергозатрат
- Используется для: проникновение в хозяина, пенетрация стенки органа

#### Тип 4: «Выживи» (survival)
- Таймер обратного отсчёта
- На паразита воздействует среда (кислота желудка, температура, ферменты)
- Игрок должен удерживать паразита в «безопасных зонах» (складки слизистой, пузырьки воздуха)
- HP постоянно капает, безопасные зоны восстанавливают / замедляют урон
- Используется для: прохождение через желудок, термическая обработка

#### Тип 5: «Размножься» (тайминг + ресурсы)
- Паразит откладывает яйца
- Нужно выбрать правильный момент (перистальтика, менструальный цикл, кашлевой рефлекс — зависит от паразита)
- Ресурс: запас яиц, ограничен
- Чем больше яиц вывел — тем выше оценка за главу
- Используется для: финальная стадия цикла

### Кампании (паразиты)

Каждая кампания — **самостоятельная история** со своим тоном и персонажем:

| Кампания | Паразит | Тон рассказчика | Глав | Уникальная механика |
|---|---|---|---|---|
| «Одиссея» | Opisthorchis felineus | Философский, усталый путешественник | 5 | Выбор правильного хозяина из нескольких похожих видов |
| «Марафон» | Ascaris lumbricoides | Энергичный спортсмен | 4 | Миграция-кольцо по органам (кишечник→печень→лёгкие→кишечник) |
| «Невидимка» | Toxoplasma gondii | Манипулятор, хитрый | 6 | Механика влияния на поведение хозяина (мини-игра «заставь мышь подойти к кошке») |
| «Два мира» | Plasmodium falciparum | Двуличный, два голоса (в комаре и в человеке) | 6 | Два радикально разных набора мини-игр для двух хозяев |
| «Терпение» | Taenia solium | Спокойный, расчётливый | 5 | Механика роста (новые сегменты = новые возможности, но и больше риска обнаружения) |
| «Вторженец» | Schistosoma mansoni | Агрессивный, воинственный | 5 | Мини-игра проникновения через кожу — уникальный экшн |

### Система оценки и тестирование

#### Оценка прохождения кампании
```
S — 0 смертей, все мини-игры на отлично, бонусные факты собраны
A — 1–2 смерти, мини-игры без провалов
B — 3–5 смертей
C — 6+ смертей, но прошёл
```

#### Тест после кампании
После прохождения — **интерактивный тест**:
1. Расставить стадии жизненного цикла в правильном порядке (drag & drop)
2. Назвать промежуточных и окончательных хозяев (выбор из списка)
3. Указать инвазивную стадию для человека
4. Выбрать метод диагностики
5. Назвать меры профилактики

Тест можно проходить отдельно от кампании (режим «Экзамен»).

### Энциклопедия

Собирается из фактов, полученных при смертях и при успешных прохождениях:
- Каждый паразит: систематика, морфология, цикл, патогенез, диагностика, лечение, профилактика
- Каждый факт привязан к конкретной игровой ситуации («Вы узнали это, когда попытались проникнуть в щуку»)
- Прогресс заполнения: % для каждого паразита
- 100% энциклопедии = нужно и пройти, и умереть на всех вариантах

### Интерфейс

#### Нарративные секции
- Полноэкранный арт среды (водоём, внутренность органа, ткань под микроскопом)
- Текстовое окно внизу (как в визуальной новелле)
- Портрет «рассказчика» (стилизованное изображение паразита) слева
- Кнопки выбора по центру

#### Мини-игры
- Полноэкранная игровая зона
- Минимальный HUD: HP, энергия, таймер (если есть)
- Всё остальное — дизайн среды (орган, вода, ткань)

#### Между секциями
- Экран перехода: схема жизненного цикла, текущая стадия подсвечена, пройденные — заполнены
- Анимация перехода между стадиями
